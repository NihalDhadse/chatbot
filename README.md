# chatbot
A modern AI chatbot built with Streamlit, LangChain, and Groq, featuring a responsive ui.


 🤖 Groq Streamlit AI Chatbot

A modern, responsive AI chatbot built with **Python, Streamlit, LangChain, and Groq**.

## ✨ Features

-  AI chatbot powered by Groq
-  Fast responses using `ChatGroq`
-  Chat history with Streamlit session state
-  Modern glassmorphism UI
-  Animated gradient background
-  Responsive design
-  Interactive suggestion cards
-  Online status indicator
-  API key stored securely using `.env`

##  Tech Stack

- Python
- Streamlit
- LangChain
- Groq
- python-dotenv
